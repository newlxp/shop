## Схема id

Для 2 курса веб-разработки используется числовой id:

```text
2 + 1 + NN + TT
```

Где:

- `2` - курс.
- `1` - направление, сейчас веб-разработка.
- `NN` - номер дисциплины в направлении, сквозной по семестрам.
- `TT` - номер контрольной точки внутри дисциплины.

Примеры:

```js
210101 // 2 курс, веб-разработка, дисциплина 01, КТ 01
211101 // 2 курс, веб-разработка, дисциплина 11, КТ 01
212304 // 2 курс, веб-разработка, дисциплина 23, КТ 04
```

Важно: дисциплины 1 семестра идут первыми, дисциплины 2 семестра продолжают нумерацию.

```bash

```

И отдельная проверка через Node.js:

- нет дубликатов `productsData[*].id`;
- `subjectsData[course][semester][*].count` совпадает с количеством товаров в `productsData`.

Последний известный результат:

